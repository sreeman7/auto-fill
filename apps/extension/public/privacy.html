auto-fill privacy policy — beta draft

Last updated: 22 November 2026

Publisher contact: A monitored support and privacy email must be added before beta distribution.

auto-fill helps you review and fill job application forms. You choose when to save information, scan a page, use cloud tools, or submit an application. auto-fill never clicks the final submit button for you.

Information used

  • Local profile: Name, contact, education and profile links you enter stay in Chrome extension local storage on your device. They are used to propose matching form values when you ask to scan and fill.
  • Application page: A user-invoked scan reads visible form labels, field types, values needed to identify already-filled fields, validation messages and the page URL. The side panel displays a review. The extension does not continuously record browsing history.
  • Account and cloud data: If you sign in, Supabase processes your email, credentials and session. The API stores your account profile, uploaded resumes, approved career facts and application tracker records in the configured Supabase project. Resume text is parsed with rules to propose facts for your approval.
  • Operational data: The API logs a random request ID, route template, method, status and duration. It does not log request bodies, search terms, tokens, resume contents or raw job URLs. A future production host may process connection information; its retention settings must be confirmed before distribution.

Sharing and purpose

Cloud features send data to the configured auto-fill API and Supabase. Google may process sign-in information if you choose Google sign-in. A job website receives the values you choose to fill there and any application you submit, under that website's own practices. auto-fill does not sell data or use it for advertising.

Your choices and deletion

You can edit or clear your local profile. Signing out removes the active cloud session from the extension. You can delete approved facts and tracker records individually. Delete account and cloud data requests removal of stored account data and resumes from the API and Supabase. If it reports an error, a deletion step may need to be retried. Removing the extension removes its local extension storage from that browser profile. Cloud records remain until deleted.

Security

Cloud URLs use HTTPS outside loopback development. Account records use server-side authorization and database row-level security. Server-only keys stay out of the extension. Permissions are limited to user-invoked page access and configured cloud origins. No system can guarantee absolute security.

Changes and contact

This draft must be completed with a working support and privacy contact and a public URL before beta distribution. Material data-practice changes will be disclosed before use.
